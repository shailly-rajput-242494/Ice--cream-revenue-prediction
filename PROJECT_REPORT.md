## 1. Introduction
This project demonstrates how Machine Learning can be used to predict ice cream revenue based on temperature.

## 2. Objective
To study the relationship between temperature and ice cream revenue and build a prediction model.

## 3. Technology Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Linear Regression

## 4. Dataset
The demonstration dataset contains two columns:
- Temperature_C
- Revenue

Note: This is illustrative sample data, not verified original YBI data.

## 5. Methodology
1. Import libraries.
2. Load the dataset.
3. Select input and target variables.
4. Split data into training and testing sets.
5. Train Linear Regression model.
6. Evaluate predictions.

## 6. Conclusion
This project demonstrates a basic Linear Regression approach for estimating ice cream revenue using temperature.
